# Get Hired Hub

Build the Get Hired KE homepage with a clean, spacious layout, primary color green, text in dark charcoal or navy, backgrounds white or light gray, accent color gold or orange for featured jobs and deadlines. Use Poppins or Montserrat for headings, Inter or Open Sans for body text. The top navigation should include Home, Categories dropdown, Services, Career Hub, About Us, Contact. And, include join WhatsApp channel button, and also a search bar front and center. Homepage sections should be search bar, featured jobs, latest jobs, categories grid, a short about snippet, and a big call to action to join the WhatsApp channel. Make it mobile first, and keep the design consistent with green icons and rounded cards. Then the next page to design is the job details page with a clear apply now button.
